# ♻️ 코드 리팩터링 및 구조 개선

프로젝트 후반부에는 전체 ROS2 노드를 다시 점검하고, 불필요하거나 중복된 로직을 정리하며 코드 구조를 단순화했습니다.

주요 목표는 가독성, 유지보수성, 주행 안정성 향상이었습니다.

## 🧩 노드 구조 정리

처음에는 실험을 반복하면서 기능이 섞여 있었기 때문에, 하나의 노드에 인식과 제어가 동시에 들어가거나, 테스트용 노드가 실행 중에도 계속 남아 있는 경우가 많았습니다.

이를 해결하기 위해 노드를 다음과 같이 재정리했습니다.
> ※ 차선 인식 기능은 별도 노드가 아닌 `self_driving` 내부 로직에서 수행됩니다.

| 구분   | 노드 이름                    | 역할                              |
|--------|-----------------------------|-----------------------------------|
| 인식   | `camera_publisher`          | 카메라 영상 Publish               |
| 인식   | `yolov5_ros2`               | 객체 인식 및 좌표 송신            |
| 제어   | `self_driving`              | 주행 로직 통합 및 PID 기반 조향   |
| 제어   | `ros_robot_controller`      | 모터·서보 제어(PWM)              |
| 피드백 | `led_controller`            | LED 상태 표시                     |
| 피드백 | `lcd_controller`            | LCD 텍스트 출력                   |


각 노드를 개별적으로 비활성화하며 동작 변화를 비교해 보았지만, 성능 면에서 유의미한 차이는 나타나지 않았습니다.  
다만, 노드 단위로 동작을 확인해 본 경험 자체는 시스템 구조를 이해하는 데 참고가 되었습니다.

## 🎯 3. PID 제어 미세 조정 (보조적 개선)
주행 안정성을 더 매끄럽게 하기 위해 PID 파라미터를 **소폭** 손봤습니다.  
이는 핵심 변경이 아니라, 과도한 조향 반응을 완화하고 곡선 구간에서 부드럽게 반응하도록 **미세 조정**한 수준입니다.

- 목표: 과민한 조향 반응 완화, 곡선 진입 시 흔들림 감소
- 방식: P를 약간 낮추고 D 비중을 높여 출력 변화를 부드럽게 함

> 주행 안정화의 근본 원인은 별도 개선(예: 입력 안정화 등)에 있으며, PID 조정은 그 이후 출력을 다듬는 보조 조치로 적용했습니다.
