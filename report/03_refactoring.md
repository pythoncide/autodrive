# ♻️ 코드 리팩터링 및 구조 개선

프로젝트 후반부에는 전체 ROS2 노드를 다시 점검하고, 불필요하거나 중복된 로직을 정리하며 코드 구조를 단순화했습니다.
주요 목표는 가독성, 유지보수성, 주행 안정성 향상이었습니다.

## 🧩 노드 구조 정리

처음에는 실험을 반복하면서 기능이 섞여 있었기 때문에,
하나의 노드에 인식과 제어가 동시에 들어가거나,
테스트용 노드가 실행 중에도 계속 남아 있는 경우가 많았습니다.

이를 해결하기 위해 노드를 다음과 같이 재정리했습니다.
| 구분   | 노드 이름                                        | 역할                  |
| ---- | -------------------------------------------- | ------------------- |
| 인식   | `lane_detect`                                | 차선 검출 및 오프셋 계산      |
| 인식   | `yolov5_ros2`                                | 객체 인식 및 좌표 송신       |
| 제어   | `self_driving`                               | 전체 주행 로직 통합, PID 제어 |
| 제어   | `led_control`, `lcd_display`, `button_input` | 하드웨어 제어 및 피드백       |
| 주변장치 | `rrc_controller`                             | 모터·서보 제어 (PWM)      |

각 노드는 독립적으로 실행되지만,
`self_driving` 노드가 모든 센서 데이터를 구독해 최종 판단을 내립니다.

이 구조 덕분에 ROS2에서 콜백 간섭이나 토픽 충돌이 사라졌고,
디버깅 시 개별 노드를 단독으로 실행할 수 있게 되어 테스트 속도도 빨라졌습니다.

## 🧠 PID 제어 튜닝
### 문제 상황
초기에는 PID 파라미터 비율이 맞지 않아,
곡선 구간에서 차량이 과도하게 흔들리거나,
직선 구간에서 반응이 늦어지는 현상이 발생했습니다.

### 개선 과정
- P 비율을 점진적으로 낮추고 D 항을 늘려 진동 억제
- 차선 중심 오프셋의 절대값이 커질수록 선형 속도를 자동 감소
- 곡선 구간에서는 속도를 0.12~0.15, 직선 구간은 0.18로 설정

### 결과
PID 튜닝 후에는 차선 유지 오차가 ±3cm 이내로 줄어들었고,
커브 구간 진입 시 흔들림이 거의 사라졌습니다.
