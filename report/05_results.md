# 🎯 결과 및 회고

이번 프로젝트의 목표였던 **ROS2 기반의 자율주행 로봇 시스템**은 객체 인식, 주행 제어, 하드웨어 피드백까지 모두 정상적으로 동작하는 수준으로 완성되었습니다.  
여러 시행착오와 튜닝 과정을 거치며, 실제 환경에서 안정적인 주행을 구현할 수 있었습니다.

## 🧪 실험 환경
| 구분         | 내용                                                                        |
| ---------- | ------------------------------------------------------------------------- |
| **하드웨어**   | MentorPi (Raspberry Pi 4B), RRC 모터 제어보드, HP60C 카메라, 브레드보드(LED·LCD·Button) |
| **소프트웨어**  | Ubuntu 22.04, ROS2 Humble, Python 3.10                                    |
| **모델**     | YOLOv5s (ONNX), OpenCV 기반 차선 인식                                           |
| **테스트 장소** | 실내 트랙(교차로, 곡선, 주차 구간 포함)                                                  |
| **주행 거리**  | 약 7~10m 루프 기반 주행 시나리오                                                     |

## 🚘 주행 결과 요약
### 1. 차선 인식 및 PID 주행
- 직선 구간에서는 오프셋 오차 ±3cm 이내로 유지
- 곡선 구간 진입 시 진동 없이 부드러운 조향 수행
- PID 조정 후 주행 궤적이 일관되게 유지됨

### 2. 객체 인식 동작
- 횡단보도 및 신호등 인식 정확도 약 92%
- 우회전/주차 표지판 인식 정확도 약 90%
- ONNX 변환 모델 사용 후 FPS 1.6~1.7Hz 안정 유지

### 3. 주차 및 회전 로직
- `right` 인식 → 부드럽게 우회전
- `parking` 인식 후 지정 지점에 정지 및 LED 빨강 전환
- 회전 및 주차 후 PID 루프로 정상 복귀

### 4. 하드웨어 피드백
- LED 색상 전환 및 LCD 텍스트 갱신 모두 실시간 반응
- 버튼 입력으로 안전하게 주행 시작/정지 제어 가능
- ROS2 통신 지연 없이 모든 모듈이 동기적으로 동작

## ⚡ 성능 비교 (Before → After)

YOLO 모델의 추론 속도 향상이 전체 시스템 반응성을 결정짓는 핵심이었습니다.  
이 변화로 인해 PID 제어, LED 피드백, 주차 로직 모두 실시간 동기화가 가능해졌습니다.

| 항목      | 개선 전 (.pt)  | 개선 후 (.onnx) | 결과        |
| ------- | ----------- | ------------ | --------- |
| 평균 FPS  | 0.52 Hz     | **1.69 Hz**  | ▲ 약 3배 향상 |
| 최대 지연   | 42초         | **0.9초 이하**  | ▼ 97% 감소  |
| PID 안정성 | 불안정 (곡선 진동) | **매끄러운 주행**  | ✅ 개선 완료   |
| LED 반응  | 불규칙         | **주기 일정**    | ✅ 개선 완료   |

## 🎥 시연 장면 요약
- 차선 인식 → PID 기반 직선 주행
- `cross_walk` 인식 → 일시 정지 후 재출발
- `right` 인식 → 부드럽게 우회전
- `parking` 인식 → 정지 및 LED 빨강 표시

실제 영상에서는 LED 색상이 주행 상태에 맞춰 즉시 변하며,
주행 도중 YOLO 인식 결과와 PID 조향이 자연스럽게 이어지는 것을 확인할 수 있습니다.

## 💡 프로젝트를 통해 배운 점
### 1. ROS2의 구조적 이해
단순히 퍼블리시·서브스크라이브가 아니라,
각 노드 간 타이밍과 큐 크기 조정이 시스템 안정성에 직접적인 영향을 줍니다.
### 2. 모델보다 중요한 추론 구조
YOLOv5의 .pt 모델보다 ONNX 변환과 런타임 최적화가 훨씬 큰 개선 효과를 냈습니다.
### 3. 하드웨어 제어의 디테일
LED 점멸 주기나 PID 응답속도 같은 작은 요소가 실제 주행 품질을 크게 좌우했습니다.

## 🏁 마무리
이번 프로젝트는 단순한 자율주행 모형을 넘어서, ROS2 기반 실시간 멀티노드 시스템을 직접 구축하고 최적화한 경험이었습니다.  
특히 라즈베리파이 환경에서의 YOLOv5 최적화, PID 제어 안정화,
하드웨어 피드백 구조 설계까지 전 과정을 직접 구현하면서, 임베디드 환경에서 “AI + 제어”가 어떻게 연결되는지 깊이 체감할 수 있었습니다.
